# Reviews (record home — template)

> **INTERNAL — delivery gate records.** Self-assessments, conformance
> scoring and findings against MathCo's own bars. Not client deliverables: a client has a stake in
> whether the work is sound, not in how we score our own discipline. The client-facing statement of
> what is unfinished is [`../docs/handover.md`](../docs/handover.md) §5.

Pre-created homes for review records, because "no artifact, no review" — a review with no written record did not happen. Each record carries: what was reviewed, by whom, date, outcome (pass / conditional / fail), follow-ups with owners.

Expected record types (use `../../templates/gate-record-template.md`):
- exit-package gate (the ARP, in the Ralliant instance)
- milestone gates
- conformance reviews
- handover readiness sign-off

Kept empty in the template — the home exists before the proof does.
